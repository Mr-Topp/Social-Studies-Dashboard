Update your Teacher Tools

New (Nov 2): this adds paper grades and exempt (EX) to your dashboard, and shows students their paper grades on their home page. It keeps everything from before (student PINs, links, class lists). About 2 minutes. Use your school Google account.

Part 1 · Teacher Tools

  1. Copy the new Teacher Tools script.
  2. Open your Teacher Tools script. (This button opens it.)
    Open my Teacher Tools script ↗
  3. Paste over the old code. Click inside the code, press Ctrl+A, then Ctrl+V, then Ctrl+S to save.
  4. Publish the new version. Click Deploy (top right) → Manage deployments → the pencil ✏️ → under Version pick New version → Deploy.

    Don't click "New deployment." That makes a new address, and the site wouldn't find it.

  5. Check that it worked.

Part 2 · Turn-in saver + a new teacher code

Already did Part 2 before (when you set up PIN slips)? Skip it. This update doesn't change the turn-in saver.

  1. Copy the new turn-in saver script.
  2. Open its script. In Google Drive, open your Class Turn-ins sheet → Extensions → Apps Script.
  3. Paste over the old code. Ctrl+A, Ctrl+V, Ctrl+S.
  4. Change your teacher code. Click the gear ⚙️ (Project Settings) on the left → scroll to Script Properties → Edit script properties → change the value next to TEACHER_CODE to 4 random words, like pickle radio canyon seven → Save.

    Write it down somewhere private. After 10 wrong tries, codes lock for 15 minutes.

  5. Publish the new version. Deploy → Manage deployments → pencil ✏️ → New version → Deploy.
  6. Done. Go back to the dashboard and type your new code. Then, for each class, open Needs attention and click Print PIN slips.
